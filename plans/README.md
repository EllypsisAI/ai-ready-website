# Plans Directory

This directory contains implementation plans for the AI Ready Website project.

## Structure

- **`active/`** - Current plans being worked on
- **`completed/`** - Finished implementation plans (for reference)
- **`future/`** - Ideas and plans for future features

## How to Use

1. Create a new plan in `active/` when starting a new feature
2. Move to `completed/` when the feature is done
3. Store ideas in `future/` for later consideration

## Plan Template

```markdown
# Feature Name

## Overview
Brief description of what this feature does

## Requirements
- List of requirements
- What needs to be built

## Implementation Steps
1. Step one
2. Step two
3. etc.

## Files to Create/Modify
- `path/to/file.ts` - Description
- `path/to/another.tsx` - Description

## Testing
How to test this feature

## Notes
Any additional context or decisions made
```
